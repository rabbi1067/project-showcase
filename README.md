# 🚀 Project Showcase

A clean and modern web app to **showcase your projects** in one place — perfect for developers who want a personal portfolio-style gallery of their work.

---

## ✨ Features

- 🎨 **Modern UI** — Clean, responsive design that works on all devices
- 🗂️ **Project Gallery** — Display all your projects in an organized layout
- ⚙️ **Easy Configuration** — Add or update projects via a single `config.js` file
- 🔍 **Project Details** — Show title, description, tech stack, and links
- 🐳 **Docker Ready** — Run instantly with Docker, no setup hassle
- ⚡ **Lightweight** — Pure HTML, CSS, and JavaScript (no heavy frameworks)

---

## 🛠️ Tech Stack

- **HTML5** — Structure
- **CSS3** — Styling & responsiveness
- **JavaScript (Vanilla)** — Interactivity & rendering
- **Docker** — Containerized deployment
